# 定位包 HTML 还原

共 8 个独立英文页面。直接打开 `index.html` 可浏览定位首页，或启动静态服务器。无安装、无构建、无外部 CDN。

```sh
python3 -m http.server 8879 --directory location-html
```

访问 `http://localhost:8879/`，原图对照入口为 `review.html`。

| 页面 | 文件 |
| --- | --- |
| 实时定位 | location.html |
| 自动动态 | activity.html |
| 手机概览 | overview.html |
| 历史轨迹 | history.html |
| 收到紧急联系 | emergency.html |
| SOS 设置 | setup.html |
| SOS 倒计时 | countdown.html |
| SOS 进行中 | active.html |

## 实现与素材

- 以 848 × 1855 的参考画布定位，按屏幕等比缩放。手机宽度下不发生横向滚动。
- 文字、面板、表单、数据卡片、主要按钮与页面交互均为 HTML/CSS/JS；不是用整张截图作为网页。
- 图标和头像从用户提供的概念图裁切，复用原有画法。部分浅色图标背景进行了透明底提取；未引入图标库，未重绘图标。
- 两张地图作为静态地图图片组件复用，包含原图地图标注；没有接入实时地图服务。地图上的选中区、刷新等为演示交互。
- 概览页的空白深色纹理背景通过内置 ImageGen 补全，提示要求仅移除前景文字和控件、保留原纹理，不生成图标。
- `assets/manifest.json` 记录主要素材的来源及裁切范围；`references/` 保存原始参考；`screenshots/` 保存浏览器截图。
- 在不同操作系统和浏览器上，系统字体与抗锯齿会有细微差异；可通过 `review.html` 逐页查看实际还原结果。

## 交互

1. 首次点击底部 SOS 按钮进入设置页；至少选择一位接收者。
2. 保存只保存到本机 localStorage，不发送。
3. 再次点击 SOS 开始 5 秒倒计时；取消、关闭或进入设置均停止计时。
4. 倒计时结束进入 SOS 进行中；结束后返回进入前的页面。
5. 设置的接收者和消息贯穿倒计时与进行中页面。
6. 独立打开 `countdown.html?freeze=1` 可查看剩余 3 秒的静态视觉状态。
7. 收到 SOS 页面作为单独接收状态保留，不与发送页混合。

这是本地交互原型。位置、消息及送达状态均为演示数据；不会实际发送 SOS、共享位置或拨打电话。

## 验证

`verification.json` 记录功能检查；截图使用 Chrome 渲染，按页面单独保存。`scripts/capture.cjs` 和 `scripts/verify.cjs` 使用当前工作环境中的 Playwright，可按本机依赖路径调整后复用。

## 2026-10-23 需求原型更新

以根目录《需求文档.md》《功能地图.md》为本轮依据，新增 `product.js`，在原有页面布局上覆盖产品行为。

- 首次访问填写本人头像、昵称、电话；保存后进入定位。资料页为 `profile.html`。
- 手机号搜索、发送申请、接收方确认共享说明、同意/拒绝/失效和解绑均可在本地演示。通过 Find a member 可进入好友申请及资料入口。
- 主导航为手机概览、定位、历史及独立 SOS；旧 Activity 地址返回定位。
- 概览区分本人和好友，好友只显示设备状态可用性；移除 Open Record / Sensitive record。
- 历史按好友与日期显示，提供最近 30 天选择；删除回放，解绑与新绑定期间限制在本地状态中检查。
- SOS 设置仅提供已绑定好友，已有配置会过滤已解绑接收者；进行中区分等待回执与明确模拟确认。
- 所有账号搜索、绑定及数据均为本地演示；没有接入真实手机号验证、推送、定位和系统报告。地图仍复用截图素材，不是实时地图，图内原始标注尚不能完整随成员动态重绘。
- 浏览器测试：`node location-html/tests/product-check.cjs`，覆盖填写资料、手机号申请、接受绑定、主路由与聊天入口移除。
