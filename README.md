# WhereTo prototype

离线交互演示，入口：`location-html/launch.html`。

解压后保留目录结构，使用 Chrome 或 Safari 打开入口文件，无需安装依赖。

包括新人资料、emoji 头像、设备概览、位置/地点、历史轨迹回放、SOS 设置与接收通知演示。手机外侧操作区提供 SOS 模拟按钮及三个可添加的演示账号。

这是本地原型；位置、设备状态和 SOS 均为演示数据，不会发送实际通知或拨打电话。资料保存在浏览器本地存储。
